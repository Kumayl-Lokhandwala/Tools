# 🛠️ Tools

A collection of small, practical Python utilities and other tools built to solve everyday problems.

I'm building **one tool a day**, keeping each project simple, useful, and easy for anyone to run.

## Tools

| #   | Tool                              | Description                                                                                                 | Language |
| --- | --------------------------------- | ----------------------------------------------------------------------------------------------------------- | -------- |
| 01  | [Audio Remover](./audio-remover/) | Remove audio from a video and save a muted copy.                                                            | Python   |
| 02  | [Rename Kit](./rename-kit/)       | Batch rename files with prefixes, suffixes, find-and-replace, and numbering, with preview and undo support. | Python   |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Kumayl-Lokandwala/Tools.git
cd Tools
```

Choose a tool from the directory above and follow its README for installation and usage instructions.
